# Jak psát poznámky

## Na webu

1. Vpravo dole klikni na **Přihlásit k úpravám** a vlož svůj přístupový klíč z GitHubu (návod se ukáže při přihlášení). Stačí jednou na každém zařízení.
2. U předmětu klikni na **Nová přednáška** nebo **Nové cvičení**, u hotové poznámky na **Upravit**.
3. Piš vlevo, vpravo vidíš náhled. Obrázek vložíš přes tlačítko nebo prostě přes Ctrl+V.
4. **Uložit** (nebo Ctrl+S). Web se zaktualizuje zhruba do minuty.

## Mimo web

Poznámky jsou obyčejné Markdown soubory ve složce `docs/semestry/`, takže je jde psát i přímo na GitHubu, ve VS Code nebo v Obsidianu.
