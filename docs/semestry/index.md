# Semestry

Každý semestr má vlastní složku, každý předmět v ní vlastní podsložku:

```
semestry/
  01-semestr/
    index.md              ← přehled semestru (rozvrh, předměty)
    geograficke-informacni-systemy/
      index.md            ← karta předmětu (šablona Předmět)
      01-prednaska.md     ← šablona Přednáška
      01-cviceni.md       ← šablona Cvičení
      zkouska.md          ← šablona Příprava na zkoušku
```
